title: Using Standard with VSCode
---

There’s an easy way to integrate Standard in VS Code—with the vscode-standardjs plugin. I made a [video](https://youtu.be/Hv8FgxJyI9Y) for this some time ago if you’re interested in setting it up.

If you follow the instructions in the video (or on vscode-standardjs’s readme file), you’ll come to notice there’s one small detail that needs to be ironed out.

Try writing a function the old way, and save it repeatedly. VS code will toggle between having and not having a space before the left-parenthesis of the function.

![](https://convertkit.s3.amazonaws.com/assets/pictures/393/2199454/content_functions.gif)

You get the same problem when you write methods with the ES6 method shorthands:

![](https://convertkit.s3.amazonaws.com/assets/pictures/393/2199455/content_methods.gif)
