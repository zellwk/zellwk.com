## Astro If Component 

One thing that consistently irritates me about Astro (and React, for the same reason) is the lack of an `if` statement. 

Instead of a simple `if`, we have to use a JSX conditional like this. 

```astro
{
  condition && (
    <!-- Markup goes here --> 
  )
}
```

This is annoying because the condition takes up space and creates indentation, which makes the code harder to parse.

I created an [`If`](https://splendidlabz.com/docs/astro/components/if/) component that simplifies JSX code above. 

```astro
<If condition={1 + 1 === 2}>
  <!-- Markup goes here --> 
</If>
```

And a [`Not`](https://splendidlabz.com/docs/astro/components/not/) component that does the opposite. 

```astro
<Not condition={authorized}>
  <!-- Markup goes here --> 
</Not>
```

[Today’s article](https://zellwk.com/blog/astro-if-and-not/) dives deeper into these components: how to use them, and also the caveats you need to know when using them.
