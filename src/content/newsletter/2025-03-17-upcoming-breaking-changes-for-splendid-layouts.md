title: Upcoming breaking changes for Splendid Layouts
---

This is probably one of the most ironic messages I’m gonna send because I’ve just ranted about breaking changes last week.

But I gotta tell you about these breaking changes in advance so you can ease into the new library as much as possible — although it’ll probably take some time before I get the documentations out.

(Life is tough, but I’m working on all the various fronts I can as we speak).

There are two major breaking changes coming with the upcoming version of [Splendid Labz](https://splendidlabz.com).

- [Splendid Layouts](https://splendidlabz.com/docs/layouts/getting-started/introduction/) and Splendid Styles will be combined into a single library.
- We’re going to ditch [the naming convention](https://splendidlabz.com/docs/layouts/concepts/naming-convention/) I recommended last year.

Today’s article goes into the reason why we’re making these breaking changes. This will be interesting if you like to hear behind-the-scenes stories and (fuck ups) that breaking changes from other libraries cause.

[Upcoming Breaking changes for Splendid Layouts](https://zellwk.com/blog/splendid-labz-breaking-changes)

Anyway, hope you have a good read.

(If you’ve been following my haphazard posts last year, you would know that Splendid Labz is a project where I’m building layouts, components, and tools that will help you it easy to build websites and web applications).

(Frankly, it’s different from other component libraries, but I haven’t quite gotten the handle on how to explain its differences yet. So, as I release more tools I’ve built for you and me, I hope the clarity comes through to me)

That’s it from me this week. Hope you have a great week.
