## Rsync with a custom port

You can rsync with a custom port by using the -e flag. It's a simple process. You can read more about it [here](https://zellwk.com/blog/rsync-with-custom-port) since it's super hard to get code looking right in emails :)

## Rsync with a custom port when you use Github Actions

Turns out, using rsync with a custom port isn't so easy because you can't add the -e flag and be done with it. We have to add the port into the known\_hosts file too.

Thankfully it's not a hard process. The hardest part is discovering what needs to be done, and I've already done the work for you :)
