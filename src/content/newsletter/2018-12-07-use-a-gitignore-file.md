---
title: Use a Gitignore file
---

If you don't want to commit a file into a Git repository, it makes sense not to have the file show up in the staging area.

You can do this with a Gitignore file.

\- Video: [https://youtu.be/xlQIABDgTOs](https://youtu.be/xlQIABDgTOs)

\- Article/Podcast: [https://zellwk.com/blog/gitignore](https://zellwk.com/blog/gitignore)

Enjoy!
