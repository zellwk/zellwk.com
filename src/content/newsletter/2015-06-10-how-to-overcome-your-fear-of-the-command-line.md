The first obstacle that’s standing between you and an automated workflow is the command line. This is because most tools that help you automate your workflow require you to use the command line. Hence, you’ll have to get comfortable with it.

But the command line can be scary.

Playing with it if feels like you’re dismantling a bomb that could go off any moment. One wrong move and that’ll mean the end of your life (your computer to be more exact).

I didn’t dare to touch it when I first began to code. I felt like the command was a tool that only the experts could use.

However, as I got to know more about it, I began to realize that the command line isn’t scary at all! It’s incredibly safe, even for beginners, and anyone can use it to help improve their workflow.

Today, I’ll like to show you why the command line isn’t that scary, and how to start to get comfortable with it.
