In the previous two weeks, you learned that there are three way to create animations:

1. CSS Transitions
2. CSS Animations
3. With JavaScript

The best way to create animations with JavaScript is to use the Web Animations API. Unfortunately, support for Web Animation API is still lacklustre, so you can’t use for production builds right now.

The best way, at this moment, is to use Greensock animation API (GSAP). It’s a library that expert animators like Chris Gannon and Sarah Drasner use.

In today’s article, you’ll learn how to use Greensock to create simple animations.
