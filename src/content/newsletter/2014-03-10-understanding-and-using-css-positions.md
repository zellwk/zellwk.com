title: Understanding and Using CSS Positions
---

Sometimes display values and floats are not enough to do everything you want them to do in CSS, one example of this is a navigation bar that sticks to the top of the window no matter how far you scroll down.

That sticky navigation bar required the use of  CSS position fixed.

CSS Positions allows you to put things in places where they normally can't be placed without the use of positions, and the ability to position things at will is one important skill would want to know.

In the post I'm sharing today, I'll explain what these position properties do, and how to use them.
