I want to let you know first-hand that I’m creating a new course right now. This time, it’s going to be about responsive typography.

**Why responsive typography?**

**First of all, typography is the most important factor in web design**. Knowing how to handle typography would eventually mean you’ll have better designed site. I don’t think I’ll need to talk about why a well-designed site is important. You know the drill :)

**Second, it turns out that good typography on one device is easy**. You just have to follow best practices set out there and you’re good to go.

Good typography on multiple devices, however, is insanely difficult. This is because best practices out there makes code more complicated (don’t they always?). You probably experienced drowning yourself with lots of code and when trying to handle responsive typography. You’re not alone, I’ve done that too.

**Third, as the web gets more complicated, the need for modular, reusable components increases**. How then, can you create typography that is BOTH responsive and modular at the same time? It’s another challenge that frontend developers like us face.

**In short, responsive typography will cover the following:**

- Basics to typography on the web
- What typography practices should you use, and why?
- Why do these typography practices work, and how they can help you improve your web design skills.
- How to implement good typography for all devices
- How to create typography that works on modular, responsive components.
