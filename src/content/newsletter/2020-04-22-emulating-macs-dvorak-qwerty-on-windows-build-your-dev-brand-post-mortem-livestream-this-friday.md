## Emulating Mac’s Dvorak Qwerty on Windows.

I write a lot. When I got my Windows PC, the first thing I did was to change the keyboard so I can use my Mac keyboard layout. (Dvorak Qwerty, as you can tell by now).

I want to show you how to do this. It’ll help if you’re transitioning from Mac to Windows (or if you want to use both at the same time, like me).

**What you’ll learn:**

1. What is Dvorak-Qwerty-⌘, why I use it on Mac, and how to set it up on Windows.
2. How I changed positions for the Ctrl, Alt, and Win key on Windows.
3. How I smoothed out the writing experience between Mac and Windows (so I can use both).
4. How I tamed the language switcher so it would STOP switching languages when I don’t want it to!

[Click here to read the article](https://zellwk.com/blog/dvorak-qwerty).
