## Using Masonry today

Did you know that Firefox lets you build Masnory layouts natively with `grid-template-columns: masonry`?

Well, I wrote up a lightweight polyfill that lets you use this with other browsers — only 66 lines of JavaScript! It even includes all the bells and whistles like resized observer and waiting for media to load.

Imagine you only need to write these two lines of code to get Masonry to work (after including the polyfill):

```html
<div class="masonry">
  <!-- Masonry items go here -->
</div>
```

```css
.masonry {
  --cols: 2;
}
```

Excited? Well I am! I've been starting to use Masnory layouts more and more in my projects because it looks great and it's now so easy to use.

- Check out [the demo](https://codepen.io/zellwk/pen/QWoQwEy) here — give it a second or two for images to be loaded 😉.
- Read [the article](https://css-tricks.com/making-a-masonry-layout-that-works-today/) if you wanna learn the techniques to make this yourself
- And grab the [Masonry utility](https://splendidlabz.com/docs/layouts/macro-layouts/masonry/#features) (provided in [Splendid Layouts](https://splendidlabz.com/solutions/layouts/)) for free. Just follow [these instructions](https://css-tricks.com/making-a-masonry-layout-that-works-today/#aa-masonry-grid-with-splendid-labz) in the article.

Hope you enjoy using Masnory today.
