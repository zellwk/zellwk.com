It has come to my attention that some of the starter kits do not work (especially the Bootstrap and Foundation ones). I’m really sorry that I discovered it only yesterday, and I’ve fixed it now.

Here are some changes you’ll see:

1. All starter kits are stripped down to a basic Sass workflow. This will help beginners who are new to workflow get starter much quickler. (And of course, less pesky terminal errors).
2. Foundation Starter kit is updated to use Foundation v6.0 (for Foundation-sites).
3. My personal starter kit now contains two additional libraries - mappy-breakpoints and Typi.

Mappy-breakpoints is a library I made to help you write media queries easily. Check out this [github repo](https://github.com/zellwk/mappy-breakpoints) if you’re interested in finding out more.

Typi is another library I made to help you write responsive typography easily. Check out this [github repo](https://github.com/zellwk/typi) if you’re interested in finding out more.

Just log in to Gumroad, and you'll be able to see the latest updates :)

Once again, I apologize for updating the starter kits so late. If you spot anything that doesn’t work well in future, please don’t hesitate to shout out at me. I’ll fix it asap :)
