I want to share these customizations with you so you can use them to rock at Visual Studio Code too.

[Click here to read the article!](https://zellwk.com/blog/mac-and-windows-vscode-keybindings)

Here’s are some examples of what you’ll learn:

1. How to open new tabs quickly
2. How to open new panels quickly
3. How to switch focus between panels quickly
4. How to shift a tab into a specific panel
5. How to close tabs when you’re done
6. How to split tabs vertically or horizontally, or even create a grid from it!
