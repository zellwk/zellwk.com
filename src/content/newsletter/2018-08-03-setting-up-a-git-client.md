Developers LOVE git. It is one of the skills you definitely need to know if you want to become a web developer.

To put it simply, Git is like a save-point system in games. It lets you save your work. If something goes wrong, you can load your work anytime and continue from there.

Git is easy to learn, and can be very useful even when you’re not coding. Unfortunately, most Git tutorials out there teach you how to use Git through the Terminal (or command line), and that’s really scary for beginners.

We’re going to do things differently. I’m going to show you how to setup Git on your computer in this video, and in the upcoming videos, I’ll explain everything you need to know about Git.

Here’s the first video of the series. Enjoy!
