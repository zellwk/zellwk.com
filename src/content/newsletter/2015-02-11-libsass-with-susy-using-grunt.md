Have you heard of LibSass? If you haven't you should really check it out. It's a C port of the Sass precompiler that we have gotten so used to.

What's best about LibSass is that it speeds up your compile times DRASTICALLY. A 200kb CSS file that takes about 5 seconds to compile with Ruby Sass only takes 0.2s seconds to compile with LibSass (That's 25 times faster). No more waiting till eternity for Sass to compile if you have a big project to work on!

I hope you're excited about using LibSass with your development workflow as well, because that's exactly what I'm going to show you today. I'll show you how to incorporate LibSass into your project with Grunt and immediately begin the reap the benefits from its speedy compile times.
