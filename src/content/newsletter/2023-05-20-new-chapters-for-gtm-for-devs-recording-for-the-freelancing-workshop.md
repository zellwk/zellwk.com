## **I’m making a component bank right now**

I’ve decided to eliminate one of my greatest frustrations regarding web development — recreating components from scratch — by creating a component bank of my own.

The whole idea is that I’ll be able to create any project, be it websites or applications, quickly without having to think about design or crafting components again.

You can think of it like a UI Library of sorts, except this one will contain almost a huge number of components, layouts, UI, and cool stuff.

I’m doing this because most UI libraries I’ve encountered either looked ugly, lacked features, or are pretty difficult to use (since you always have to code around many weird quirks).

So my component bank will be built in a way where:

1. Theming is simple
2. Using it is simple
3. And every component packs essential functionality and accessibility features

This will take a while to create since I have a big plan and dream for it. (And this is pretty complex).
