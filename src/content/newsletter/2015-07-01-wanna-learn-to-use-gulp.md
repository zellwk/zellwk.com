You’ve heard me talking about Gulp js for a while now, but I’ve never sat down and made a tutorial for it yet.

I just wanna let you know that a Gulp tutorial is finally here!

This week, I want to share with you part one of a two-part gulp tutorial that’ll show you how to install Gulp, how to write a realistic gulp task and how to use a Gulp plugin.

In the first part of this tutorial, we’ll focus on installing Gulp, creating a basic Gulp task and then bring it up a level by adding a few plugins to compile Sass to CSS.

As a bonus, I’ll also show you how to reload the browser automatically whenever you save your styles file.
