## Building and Publishing a VSCode Theme with AI's help!

I've always felt that coding up a new theme is one of the most daunting tasks ever (especially after reading [Sarah Drasner's article](https://css-tricks.com/creating-a-vs-code-theme/) on it).

So I've always said "hats off" to the people who dared to create their own theme.

But in a strange twist of fate, I created my own code theme and published it too. I call it [Twilight Cosmos](https://marketplace.visualstudio.com/items?itemName=zellwk.twilight-cosmos-theme).

<Image
  src="/src/assets/blog/vscode-theming/html-css-js.png"
  alt="Example of Twilight Cosmos theme showing HTML, CSS, and JS samples"
/>

It looks dope (to me).

The process I took to build this theme was extraordinary.

1. I didn't start off wanting to make a theme!
2. I just wanted a nice syntax highlighting theme for my code examples (for my latest design)
3. And I found a way to test this syntax highlighting theme easily (with Claude's help)
4. Then realized I wanted to take it further. So I asked Claude for more help (ha).
5. And eventually I made a system to make it easy to edit any theme...

I was quite excited about the whole process, because, like I said, it was an impossible task for me until recently!

So I wrote up two articles — one for how I built the theme, one for how I published it — and CSS Tricks was happy to publish it!

Here are the links:

- [Making a coding theme](https://css-tricks.com/no-hassle-visual-studio-code-theming-building-an-extension/)
- [Publishing a coding theme](https://css-tricks.com/no-hassle-visual-code-theming-publishing-an-extension/)

You'll see what I asked AI to do — hopefully this can help you figure out how to use AI better in your own projects :)

(It's really powerful now). But of course, you have to hold the reins...
