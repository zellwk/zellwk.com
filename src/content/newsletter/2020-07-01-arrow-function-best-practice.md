When `this` is used in an arrow function, `this` will be the `this` value in the surrounding lexical scope. This specific feature of Arrow functions changes MANY things, so there are two best practices you need to know.

1. Don't create methods with arrow functions
2. Create functions INISDE methods with arrow functions
