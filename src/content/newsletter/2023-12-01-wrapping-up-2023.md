I hope 2023 has been treating you well!

I’ve begin to come out of my shell and blogged since July 2023. Those were my first steps to step out of a huge depression. It was difficult. (And I’m still in one).

Over the last few months, I came to realize that I hate writing _just_ technical content.

After all, I’m a human, and you’re a human too. Instead of writing purely technical articles, I want to have more connection.

- I want to know how you’re doing.
- I want to let you know how I’m doing.
- I want to know if there’s any way I can help you too.

So [let me begin by sharing how 2023 went for me](https://zellwk.com/articles/december-2023) — it sucked.

## CSS Layout Patterns

On the bright side, I’m beginning a new project called CSS Layout Patterns.

The idea here — is to create a library of code snippets that solves 99% of layout issues for all of us.

So we can focus on far more important things (than reinventing layouts all the time).

I’m really excited about this project because I can see its benefits when I’m done with it!

[Check this link out if you’re curious](https://magicaldevschool.com/css-layout-patterns), and be sure to get a free layout in the process!
