Continuing from where we left off last week, I'm going to show you how to setup a Git remote and how to push to a Git remote.

First, clarification of some terms.

\*\*A Git remote\*\* is a repository stored somewhere else on the internet. It can serve as a backup. If your computer crashes, you can always get the latest version from the remote back onto your computer.

\*\*To push to a git remote\*\* means to put your changes from your computer onto the remote.
