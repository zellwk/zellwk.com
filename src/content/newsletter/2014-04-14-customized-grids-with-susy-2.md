Hey, its been a while since Susy 2 was officially released. Susy 2 is the ultimately headache solver I found for creating CSS Grids.

Instead of relying on adding additional css classes like Foundation and Bootstrap, you can use any class that is already present in your website, and create a grid out from it.

If you have tried Susy previously, you're definitely going to love Susy 2.

Even if you haven't tried Susy, I bet you're still going to love Susy 2 :)

The downside is, Susy 2 documentation can be a pretty tough to read through. I've went ahead and created a very simple tutorial for working with Susy 2 instead.
