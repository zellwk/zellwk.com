You can find the docs [here](https://splendidlabz.com/docs/layouts/getting-started/introduction/).

If you’ve purchased Splendid Layouts, use the [forget password](https://splendidlabz.com/auth/reset-password/) feature to login and get access.

If you haven’t, I’m gonna say that this is the best thing since slice bread for Layouts — I’ve been using Splendid Layouts to create sites and it has helped me reduce a ton of layout woes.
