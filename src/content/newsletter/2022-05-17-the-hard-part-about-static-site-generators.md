There is a steep learning curve for someone who’s going from basic HTML, CSS, and JavaScript, to building a website with a Static Site Generator.

There are two major blockage points:

1. How do you use a Static Site Generator?
2. What if you screw up SEO?

We’ll cover both of these points today.

## How do you use a Static Site Generator?

All Static Site Generators share the same principles:

1. You split HTML up into chunks
2. You include these chunks into specific HTML files
3. You run a command to compile the chunks into the HTML files.

But all Static Site Generators behave differently. You want to consider which one to use because adopting a new ecosystem takes energy and effort.

There are lots of decisions to be made. You have to consider:

1. How do you write pages
2. How do you include your assets (like images, CSS, JS, SVGs, etc)
3. How do you create a good folder structure
4. How do you create reusable components
5. … _The list goes on_

**There are lots of decisions to make when you build your first website with Static Site Generators**. This is why there is a steep learning curve—you have to learn about the decisions you have to make.

The problem is documentations don’t tell you about the decisions you need to make.

The documentation for each Static Site Generator is built to teach people how to use their Static Site Generator. They don’t care about what you need to know to make a good website. In fact, most Static Site Generator documentation assume you know what you need to know.

## What if you screw up SEO?

SEO stands for Search Engine Optimization.

People who are switching over from CMSes like Wordpress to Static Site Generators have a fear of screwing up SEO. And that’s understandable.

If you screw up SEO, your site doesn’t get listed on search engines like Google. Screwing up is bad because you want people to find your website!

The truth is: SEO is not as hard as you think. You just need to get a few things right:
