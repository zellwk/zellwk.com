**My story on Learning JavaScript**

Two months after I resolved myself to learn JavaScript, I had an encounter with a client. The client wanted me to build a carousel that looked like this:

![](https://convertkit.s3.amazonaws.com/assets/pictures/393/959734/content_image5.png)

At this point, I’ve already researched carousel plugins for a week, and I knew from the sight of this component that I have to code it up from scratch. There weren’t any plugins that could make a two-row carousel like the one my client requested.

I argued against building the component. I came up with all sorts of excuses. Why? Well, I was afraid I wouldn't be able to make this component because my JavaScript skills sucked.

My project manager (at that time) wanted an estimate from me. He wouldn’t take “no” for an answer.

I took a pause, took a deep breath, and said “Four days”.

From my perspective, I didn’t have a choice. I could either give an estimate or risk showing the world that I’m a lousy developer.

“Do it”, he said.

Fuck me.

My fate is sealed. I need to deliver the component in four days, or my reputation goes to shit. There’s no way out of the mess I created.

To make the custom carousel, I had to make a jQuery plugin (jQuery was required to write any decent cross-browser JavaScript then). I couldn’t do that yet, not with my skills I had at the time.

So, I did the only thing I could think of—I took the closest plugin I could find, ripped it apart, studied it thoroughly, and built a component from the ground up.

Long story short, I got stuck with countless new concepts, banged my head on a solid brick wall and felt incredibly stupid for a few (three, to be precise) nights.

Somehow, I managed to make a prototype of the plugin by the fourth day. It was still shit. I only made the double-row carousel part; no responsive capability; no swiping functionality; none of the frills that would make the component work as it ideally should.

I delivered the prototype nevertheless. The client was happy that their “vision” worked, and I saved my ass, for now.

From the outside, this was another moment where a developer showed a workable prototype. From the inside, however, it was a completely different story.

I used to think it was impossible for me to learn JavaScript. I didn’t have any programming background, but this moment changed everything — I built a component — I started believing I can learn JavaScript.

Looking back, that was the moment where I began to internalize JavaScript principles. From that moment onwards, I built all my components from scratch and learned ton with each component. My JavaScript skills became better and better over time.

Now, JavaScript doesn’t faze me. I’m confident I can find a solution for any potential problems I face, even if no solutions are present on Google.

That’s the story of how I learned JavaScript.

**The lesson behind the story**

The real challenge that stopped me from learning JavaScript was my disbelief — I didn’t believe I would be able to learn JavaScript, because I don’t have a programming background.

When I resolved myself to learn JavaScript, I told myself that I’ll learn it, regardless of what happens. It doesn’t matter if I have a programming background or not. I’ll learn it.

Without this resolve, I probably would have given up when my project manager forced me to give an estimate. I probably would have said I couldn’t do it, and requested him to bring in an additional developer, a senior, if possible.

But I didn’t.

I faced the challenge head on and gained confidence in my JavaScript skills as a result.
