---

A student asked why I switched over from Sublime Text to Visual Studio Code, and he’s wondering whether he should switch too.

I made a quick video to answer the question. Watch it if you’re wondering whether you should switch :)

[https://youtu.be/6GFJBgTnqnE](https://youtu.be/6GFJBgTnqnE)

Bottom line: Switch if you’re unhappy with Sublime Text. Don’t switch if you’re already happy with it. Time is limited. Spend it wisely.
