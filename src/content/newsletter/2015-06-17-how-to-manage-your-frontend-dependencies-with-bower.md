I want to introduce you to a dependency manager for frontend libraries. It’s called Bower.

Dependency managers like Bower help you reduce the time and energy you need to spend hunting around the web for libraries like Susy and jQuery by helping you **install, update or delete libraries with a single command**.

It’s really simple. Here’s how you would install a library with Bower

$ bower install jquery --save

You'll want to use the installed libraries in your project next, and the actual steps differ slightly depending on whether you're adding a JavaScript library or a Sass library.
