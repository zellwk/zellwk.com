## Splendid Labz v1 release

Splendid Labz (a whole group of libraries I’ve been working on) is finally released!

You can find the page at [https://splendidlabz.com](https://splendidlabz.com).

Splendid Labz contains lots of stuff to help you make websites and applications — it’s **built for small founding development teams** that **prefer writing good code**.

The libraries within can largely be grouped into six categories:

- Astro
- Svelte
- Layouts
- Styles
- Tailwind
- Utilities

The documentation for Layouts is most complete of all. Others… well, let’s just say they’re in various stages of WIP (work-in-progress).

I’m working on the Svelte library documentation right now so it should be the one that will get updated first. The rest will get updated over the course of the year.

Two really really important things to note:

### Splendid Labz is Free(mium)

**All of the libraries built into Splendid Labz is free** — I’ve decided to allow anyone to install them from the npm registry so you can use them for absolutely zero dollars.

**The basic documentation on the site** (which contains explanations, feature introduction and sufficient code examples) **will also be free** — this is to introduce to you what you’re actually getting with this library.

**Advanced, in-depth, documentation will cost some money**. Not much, just a little bit, because:

1. Technical writing is one of the hardest things to do. (Building stuff is so much easier).
2. I think I’ve done really good work with this library and the technical writing, so I kinda want to reward myself a little bit.
3. I believe the people who value my work (who value more fun, and less painful coding experiences) will absolute find this library a steal.

To be honest — this library is the best thing I’ve created so far. It has changed the way I code so much (made it so much easier) that I can never go back to the way it was before.

I know it’s kinda like a pretty high praise for this and you might want to take it with a pinch of salt. Totally understand. It’s not easy to explain what I’m building here with a couple of words… but perhaps a series of video tutorials would do the trick. I hope to release those later this year too.

### For people who purchased CSS Layout Patterns

If you have missed the news, CSS Layout Patterns has been pivoted to Splendid Layouts (one of the libraries within Splendid Labz).

If you have purchased CSS Layout Patterns, you will be given a 2-year license for Splendid Labz as thanks for jumping onto the project early. Hope you like it ❤️.
