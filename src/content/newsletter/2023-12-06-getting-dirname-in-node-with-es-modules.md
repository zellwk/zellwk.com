If you haven’t switch over to ES Modules when using Node, you probably should — that’s because ESM is supported almost everywhere now and many useful libraries already support ESM.

One of the problems with turning on ESM support in Node, is that we lose the ability to get the path to the directory easily.

Previously, we can use `__dirname` to get it.

But no longer.
