## Building a Real Blog Easily in Astro

Most tutorials online talk about building a simple Astro blog that contains the most basic features — like adding tags, description, titles, maybe even a publish date.

But for a real blog that is useful in the real world, we need more features like:

- Having an easy way to know what is the chronological order of files
- Being able to update the article
- Create excerpts
- Filter for published posts based on a `published` status or according to the published date
- The ability to sort the posts in reverse chronological order easily

All of these are features that I've built into my blog. They make it even possible for me to keep writing because they smoothen out the creation process for me.

And I would like you to be able to [get all of this for yourself](https://zellwk.com/blog/real-astro-blog-made-easy/).
