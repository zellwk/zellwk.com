## Moving From Vanilla JS to Frameworks

This is the third and last project I’m announcing for the first quarter of 2024.

My confidence in JavaScript frameworks has soared after working with Astro and Svelte the entire year — especially after spending lots of time building Splendid UI (a component library for Astro and Svelte).

I’m now ready to take people on the journey to become pretty good at using any JavaScript framework — through the use of Astro and Svelte.

As usual, I’ll explain everything you need to know, including but not limited to:

- The changes in mentality you have to adopt
- How frameworks work
- How to best use frameworks
- How to write effective code when you use frameworks

This will be a Bootcamp of sorts so it will be a small and intensive class — guaranteed to make you a framework wizard in a couple of weeks.

I’ll tell you more about this in late February.
