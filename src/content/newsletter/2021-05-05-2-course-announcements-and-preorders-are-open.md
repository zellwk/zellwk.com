## Essential CSS

CSS can be hard to learn for many people. Most teachers teach you how to use a framework like Bootstrap and Foundation (and more recently, Tailwind) so you can build sites quickly.

While these frameworks let you build decent websites quickly, they also limit your creative freedom with what you can do. For example, you can't really customize a Bootstrap website much. Everything you make will look and feel... like Bootstrap. (Ditto for other frameworks).

But CSS doesn't limit you to Bootstrap or any framework. It gives you the power to make many beautiful things. You don't have to be limited by what others can provide you with. Your imagination (and of course, skills) is the limit here.

**In Essential CSS, we want to bring creative freedom back into your hands.** We want to give you the power and confidence to create and style any website you want, a website that is going to work on all devices. And you know this website is going to be good.

It's your website, it's your power, it's your freedom. We're here to give you the support you need to make your website a reality. So you don't have to be limited by anyone or anything when it comes to building and styling your website.

By the time you're done with Essential CSS, you will have the knowledge to build and style a basic website from scratch without using libraries or frameworks.

This course is great for:

1. Complete beginners who're interested in learning to build websites
2. Folks who want to have a deep understanding of modern CSS and web development concepts.

We will be covering these things:

1. What is HTML and how to use it
2. What is CSS and how to use it
3. Understanding fundamental web development concepts
4. How to use the Devtools to debug your CSS (diving into details for more complex things like Grid and Flex)
5. Understanding the box model and its behaviours
6. Basic properties like `margin`, `padding`, `border`, and more.
7. Advanced stuff like `grid` and `flexbox` and how to use them for layouts in a flexible medium for a wide range of devices.
8. Advanced properties like `min-content` and `aspect-ratio<br>`
9. Basic font properties to insert custom typography into your website so it brings personality into your design.

## Understanding Asynchronous JavaScript

Asynchronous JavaScript is one of the most important aspects of JavaScript today. If you know how to use it you can build interactive applications by fetching and rendering data on the fly without having to refresh a website. This gives us a chance to create better experiences for our users.

Unfortunately, Asynchronous JavaScript is hard for beginners to grasp because there are many underlying concepts you need to understand before you can use it. These concepts are often not explained in order.

For example, you need to:

1. Understand that JavaScript is single-threaded
2. Understand the event loop and how it works
3. Understand what are callbacks and how to use them (and why they're already asynchronous)
4. Understand how to fetch data with XHR and Promises
5. Understand how to read API documentation (so you actually get the data you want)
6. Understand how to authenticate yourself as you make a request (because most APIs need authentication)
7. Understand how to debug any request errors and what to do with them.

Understanding each topic takes time and effort. You have to piece together a series of information that seems to be "common sense", except it isn't common sense to you yet.

**In Understanding Asynchronous JavaScript, we want to help you understand asynchronous JavaScript so you can use it to build delightful applications** for the people you're concerned with. We want to help you give them a delightful experience.

By the end of the course, you will be able to:

1. Understand how to use Asynchronous JavaScript effectively
2. Understand API documentation and how to use them
3. Know how to authenticate yourself so you can use most APIs out there in this world
4. Be able to build stuff that derives data from multiple sources in a performant and effective manner
5. Make components with great UX using Optimistic UI (so your user doesn't have to wait while you make the request)

In short, we'll be diving into lots of details about theory. We will also be using those theories to build things that are practical and usable.
