## Image Systems is fully released

[Practical Astro](https://zellwk.com/courses/practical-astro/): Image Systems is 100% done and fully released. You should be able to access it in the [student portal](https://students.magicaldevschool.com/) if you have gotten a [courses](https://magicaldevschool.com/join/) subscription or if you have purchased [Practical Astro](https://zellwk.com/courses/practical-astro/).

**Like all of Practical Astro, this chapter contains two very important things:**

1. The code and components make it really easy to create things in Astro. (Most of the time you just have to import the components and use them).
2. The background knowledge of the necessary ingredients to create an elegant component that makes it easy for you to use things.

And **we simply deep dive into images in this chapter**. It contains things you need to know about images, videos, GIFs, SVGs, and even asset caching for GitHub Actions.
