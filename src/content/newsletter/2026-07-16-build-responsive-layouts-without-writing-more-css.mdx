## Build Responsive Layouts Without Writing More CSS

One of the things that Tailwind really unlocked for me is the ability to build responsive layouts without writing more CSS.

By this statement, I don't mean I transferred the CSS from my CSS file into an HTML file — it's just silly to think that you're not writing more CSS that way.

I really mean what I said because the structure for creating responsive layouts can be built in CSS and made possible with Tailwind.

And [in this article today](https://zellwk.com/blog/building-responsive-layouts-without-writing-more-css/) I am showing you more about what goes behind the scenes to make this sort of thing happen.

## Practical Astro Upgraded For Astro v7

Astro recently upgraded to version 7. I upgraded my sites yesterday and did a quick check to make sure things are running smoothly.

While I was doing that, I also upgraded the things I've noticed into [Practical Astro](https://zellwk.com/courses/practical-astro/): Content Systems. There are two major things you need to know about the Content Systems changes at this point:

1. We need to set `compressedHTML` to `true` to let the [Markdown component](https://css-tricks.com/markdown-astro/) continue working.
2. I would suggest you don't use Astro v6, but instead migrate to v7 straight away. I say that because v6 had some problems between Astro and MDX, which can make authoring a pain in the ass.
