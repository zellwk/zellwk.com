If you’ve been building websites or web applications for a while, you know how important SVGs are — they provide us with scalable graphics which we can use for icons and custom illustrations.

One of the most painful processes for using SVGs, is that you have to export the icons from Figma (or whatever your design tool is), put them into your project somehow, and then reference that icon.

Now that process can become so simple that you just have to specify an icon set and the icon name and poof, you get the icon you want.
