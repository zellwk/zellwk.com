One of the major blockers between using JavaScript and using frameworks is the mental model between the two.

Simply put: How do you get from `document.querySelector` and `document.addEventListener` to something like a React component?

This translation is lost for developers. As a result, we feel defeated. We don't believe we can make something as amazing as a framework — even if the framework is for ourselves only.

But the process isn't magic.

Frameworks are made entirely out of JavaScript, so you have the capability to do it too. It's about sitting down and understanding what actually goes on.

That's what we're going to do in this new module I'm revealing today.

## From JS to Frameworks

In this module, we will learn how to use a framework (like React/Vue) by building one ourselves. This approach gives you two benefits:

- You get to learn how to use a framework since you understand the principles behind it.
- You get to see how to use Vanilla JavaScript to build something complex, which will then bolster your confidence in JavaScript going forward
