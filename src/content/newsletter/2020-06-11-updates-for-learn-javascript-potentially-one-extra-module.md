## Potentially adding one more module

I wanted to give you some heads up about what’s coming up next.

I promised 20 modules of Learn JavaScript. Module 20 will be about creating a single-page app. This module will be useful for many of you who’re learning to create single page applications with frameworks like React and Vue. I’ll teach you things like routing and localStorage. If you have any questions about Single page applications, feel free to hit reply and let me know!

Next, I’m thinking of creating an extra module - Module 21 - which will be titled “From JavaScript to frameworks”. I want to write about going from vanilla JavaScript to writing something similar to React. Of course, what I’ll explain will be simple (not full-featured like React).
