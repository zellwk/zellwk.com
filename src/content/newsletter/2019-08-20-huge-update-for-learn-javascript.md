## Keyboard lessons

When it comes to keyboard, **we need to think about people who use the keyboard on a daily basis.** It’s not just keyboard shortcuts!

And **keyboard shortcuts are tough to****get right**. There are lots of browser and operating system inconsistencies (I’ll blog about them eventually). For example:

1. Pressing `Alt` and `d` on Mac gives you `∂`, but pressing the same keys on Windows give you `d`! 🤯
2. Mac users use Command as a shortcut modifier while Windows users use Control as a shortcut modifier. But you detect them differently on the web! 🤯

I spent a TON of time writing and re-writing the keyboard lessons to make sure the lessons informs but doesn’t overwhelm. The lessons you’ll get are concise and succinct, you’ll never find the same quality elsewhere.

For now, I released 10 lessons in the series. Much much much more to come. **Every component can benefit from good keyboard support.** You can look forward to improving everything you built!

## Updated component lessons

When I started writing Learn JavaScript WAY back in the past, I did something silly. I added `outline: none` to my links and buttons. `outline: none` removes focus from the keyboard Tab navigation. You should never remove focus.

But why did I do it?

I added `outline: none` because I thought I could emphasize the importance of focusing when I reach the keyboard part of the lessons.

That was a big mistake. I realized it would be irritating for you to fix the `outline: none` problem for every component you’re going to build. So **I went back and reworked on all the components.**

Which means:

1. **Fresh updated lessons** coming up for each component! Lessons will be more clear and more concise than it was previously 😄.
2. I have to spend much more time than I expect to work on Learn JavaScript. **I’m not even sure I can meet the January 2020 deadline anymore**. 😭

But I promise to do my best. I’ll work hard and get the lessons to you asap.
