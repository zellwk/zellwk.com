title: Three ways to create animations
---

Many of you wanted to know how to create interactive web animations. So, today, let’s take a break from Javascript basic lessons and talk a little about animations.

There are three ways to create animations for websites/webapps.

1. CSS Transitions
2. CSS Animations
3. With Javascript

The simplest one of them all is CSS Transitions. In today’s article, you’ll learn how to use CSS Transitions to create animations. For the next two weeks to come, you’ll learn how to use CSS animations and Javascript to create your animations.
