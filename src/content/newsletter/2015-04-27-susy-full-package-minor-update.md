title: Susy Full Package minor update
---

I recently discovered that Bootstrap changed the way its folders are organized since version 3.3.4 and above. This means that the susy-bootstrap starter kit has became obselete. That would have sucked if you used Bootstrap, so I updated it already :)

One more thing. You would have ran into an error if you tried to do `gulp build` with the Susy Templates. I fixed that in this update as well.

You can find the updated package in your Gumroad Library at [http://gumroad.com](http://gumroad.com/).
