title: Better APIs for Mutation Observer and Intersection Observer
---

Have you felt that Mutation Observer and Intersection Observer are somewhat confusing to use even though they’re great APIs?

Well, I felt that way, so I went ahead and refactored them both into simpler versions that we can use easily.

I documented the process in [an article over at CSS Tricks](https://css-tricks.com/a-better-api-for-the-intersection-and-mutation-observers/) so you can follow along the refactoring process if you like to.

If you prefer to use these simpler versions directly, feel free to go check them out at [Splendid Utils](https://splendidlabz.com/docs/utils/).

- [Mutation Observer](https://splendidlabz.com/docs/utils/dom/mutation-observer/#features)
- [Intersection Observer](https://splendidlabz.com/docs/utils/dom/intersection-observer/#features)

Splendid Utils is going to be part of Splendid Pro. (Details will be released soon — you’ll be able to grab an early-bird release price if you stick around for a bit 😉).

For now, you can view the instructions to use these utilities through the [CSS Tricks article](https://css-tricks.com/a-better-api-for-the-intersection-and-mutation-observers/) without paying a single cent.
