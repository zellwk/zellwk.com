I was updating my VS Code settings last week to improve my web development setup — and I realized that this shit is _hard_. I mean, I took around 2 days to google around and try to create the ideal setup that I want for my coding environment…

And we both know the coding environment is one of the most important things for a developer…

If you set up your coding environment with the right Linters and Formatters, coding will be very simple. If you don’t, coding will be a nightmare. Why? Because linters and formatters help you catch many errors and speed up the development process (and also, _remove a lot of headache you will face from your constant typos_)!

**So** **_you_** **_need to setup your coding environment._** There should be no exceptions unless you like having a painful development experience.

Now you know the importance of the environment, the next step is to configure this environment such that it works for you. This is a difficult task because there are so many options available today (hence my 2 days of research).

The good news is: You don’t have to do any of that difficult work because I’ve narrowed down the best configuration possible for you.

There are two possible setups:

- One for Beginner and Intermediate Web Developers who work with HTML, CSS, and JavaScript
- And another one for Advanced Web Developers who work with frameworks like Astro, React, Vue, Svelte, MDX, etc.

Today I’m going to show you how to setup the perfect environment for Beginner and Intermediate Web Developers.
