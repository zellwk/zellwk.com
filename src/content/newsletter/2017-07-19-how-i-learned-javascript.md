---
title: How I learned JavaScript
---

This may come as a surprise to you. I wasn’t always good with JavaScript. In fact, I rejected JavaScript in my early years. I argued against using it. I built websites that only required HTML and CSS as much as possible.

The honest truth is — I was afraid of JavaScript. I couldn’t understand any of it. Even though I’ve read many tutorials and books, nothing about JavaScript registered in my head. I can’t remember any JavaScript. I’m always stuck whenever I face an empty JavaScript file. I just can’t make anything from scratch. I just didn’t know how to.

It sucked.

One day, I was driven to nuts by a client who wanted a functionality that required JavaScript. No plugin out there had it, as far as I could tell. I was driven up the wall.

I told myself I’m going to learn to code JavaScript from scratch. No more plugins. No more modifying other peoples' code. I’m either going to become good enough with JavaScript or die trying. Having a difficult client breathing down my neck doubled my chances of death.

But I’m thankful for this situation. It strengthened my resolve. That’s where my JavaScript skills took a turn for the better. Now, I’m confident I can find a solution for any problems I may face, even if no solutions are present on Google. I even became confident enough to write about JavaScript on my blog.

The process wasn’t easy. I wrestled with confusion and overwhelm every night. I felt I was the dumbest person on Earth. It took many months before I finally became confident with JavaScript.

I learned the ultimate lesson through the process. Without it, I’d probably still be struggling with JavaScript today. I’ll tell you more about it tomorrow.
