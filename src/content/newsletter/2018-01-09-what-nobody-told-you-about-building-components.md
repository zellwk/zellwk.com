Have you learned quite a bit about JavaScript already, but still feel stuck when you build components?

Well, the most common reason people cite is “I don’t know how to think like a developer”.

Neither did I when I started coding.

After learning to build a few components, I realized that learning to “think like a developer” is the same as learning to think like any other individual when they try to solve problems.

**You need to break down the component you’re trying to build into tiny pieces, solve for these tiny problems, then assemble your tiny solutions into a coherent whole.**

And while you’re at it, to build components, you need to have sufficient HTML and CSS knowledge, or you won’t be able to fathom how components get built in the first place. (Nobody told you this, right?)

You’ll see what I mean when you read this super popular article: “[How to think like a developer](https://zellwk.com/blog/think/)”.
