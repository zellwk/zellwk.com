## LocalStore — a library to make localStorage easier to use

One of the problems with localStorage is it takes in only string values. If you want to save an object, you have to convert it into JSON with `JSON.stringify`.

When you retrieve objects from localStorage, you need to convert the JSON value back into JavaScript with `JSON.parse`

This process is troublesome because you need to use `JSON.stringify` and `JSON.parse`.

We make this process much easier with localstore.

[Check it out](https://zellwk.com/blog/library-for-localstorage/) if you use localStorage often.
