title: Have you thought of using template engines to speed up your development process?
---

Have you heard about template engines like Jade, Swig and Handlebars? Do you ever wonder what they are used for, and how to use them?

Well, template engines are awesome tools that can help you speed up development process by helping you do two things.

1. It lets you break down a huge HTML file into smaller, more modular HTML files
2. It lets you use data to populate your HTML files

These two combined help you write lesser, more modular code that’s incredibly easy to change!

What’s more, you can already start using them by if you’re a build tool like Gulp!

The only thing that may be stopping you is understanding how to use them, and how to set them up with Gulp.

That’s where my article today come in. It shows you everything you need to know about template engines and how to set it up with Gulp.
