title: Faux Subgrid
---

I was super excited when CSS Grid landed in major browsers back in March/April 2017. I thought CSS Grid was going to change the way we make layouts; it did.

Unfortunately, even though CSS Grid has landed, subgrid (which I consider one of the most important CSS Grid features) didn’t.

But thankfully, there’s a way to create subgrids with pure CSS (no hacks at all!). This method works with all browsers that support CSS Grid. You can read all about the method in today’s article :)

[https://zellwk.com/blog/faux-subgrid/](https://zellwk.com/blog/faux-subgrid/)
